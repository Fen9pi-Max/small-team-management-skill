> 彼得·费利克斯·格日瓦奇（Piotr Feliks Grzywacz） | [cangjie-skill](https://github.com/kangarooking/cangjie-skill)(RIA-TV++ v2.5)蒸馏 | 17 张能力卡,单入口路由式

## 能力清单

| 能力 | 重要度 | 解决什么问题 |
| --- | --- | --- |
| 抱怨→期望转换（接发球对话） | critical | 下属或同事向我抱怨时不知道怎么接话；把发牢骚转化为具体的下一步行动；成员来汇报失误时避免训斥引发辩解；想让团队里敢抱怨、抱怨转入地下后重新打开心声渠道 |
| 冲突调解与两类对立 | high | 两名成员发生情绪化冲突需要调停；判断团队里的对立该鼓励争下去还是介入踩刹车；成员A来抱怨成员B时引导直接沟通；价值观/路线根本分歧反复发作不知道怎么办 |
| 员工体验与理念共创 | low | 设计新成员从录用到融入的入职体验；低成本提升团队归属感与共鸣；把员工感受从口号变成可设计的触点清单；全员共创或修订团队理念；开口前预判对方感受、避免坏体验 |
| 实验主义与创造性混乱 | medium | 把方案从完美主义拖延里捞出来快速推进；用唱反调打破"大家都这么做"的固化常识；判断并改造只汇报不推进的死气沉沉例会；决定是否放弃或调整执行中的计划；区分哪些工作保留混乱、哪些琐事常规自动化 |
| 反馈与前馈循环 | high | 给下属做反馈不流于形式；在任务开始前把问题和风险消灭掉；处理空手来问"怎么办"的求助；打破反复返工/同类失误重演的循环；决定执行进行中要不要当场纠正 |
| 高效团队5要素诊断 | high | 系统诊断自己的团队是否具备高效团队5要素；判断团队问题出在哪个要素并排改进优先级；设计增强安全感团队活动（人生旅程）；用统一口径评价团队效率而不是凭感觉 |
| 整合型管理者与做减法 | high | 管理者忙于一线交付、想转型却不知从哪减起；判断哪些工作该委派给成员、哪些该自动化或外包；摆脱"人手不够必须再招"的固定思维；培养下属和下一代管理者；识别团伙化管理者或自查自夸拉帮结伙倾向；让团队在管理者不在场时照常运转 |
| 卓越管理者8项特质自检 | medium | 对照8项特质自检自己的管理水平；定位自己作为管理者的短板特质；判断"当好教练"这一项是否合格；了解谷歌实证的管理者评价标准 |
| 管理者姿态：袒露弱点、谦逊与性善论 | medium | 管理者该不该向成员承认错误或示弱；怎么开口请成员帮忙加班赶工；判断这次对成员该不该严厉、严厉的边界在哪；想放下完美上司人设、与成员建立伙伴关系 |
| 管理者职责与经营者视角 | high | 排查成员表现不佳该从管理者还是成员找原因；自查管理者职责履行情况（3项基础+5项机制前提）；用经营者视角三问检验团队工作价值；区分短期/长期/实时三种绩效避免只盯短期 |
| 团队机制设计库 | high | 为团队设计或选型机制（周报、认可、协作、交流）；避免照搬其他公司的制度；把团队瓶颈转成机制方案并定参数；试用并迭代或替换机制；决定规则的载体（当场纠正而非员工手册） |
| OKR 制定规则 | critical | 制定季度团队或个人 OKR；把 KPI 式或岗位职责清单式的目标改写为合格 OKR；校验 OKR 野心与质量（70% 口径、SMART、非流程维护）；运行 OKR 周检视与无意义弃用；判断 OKR 与考核的关系（不直接挂钩） |
| 一对一面谈与教练提问体系 | critical | 设计并执行每周一对一面谈；1on1 不知道谈什么或总变成进度会时改造话题结构；用 GROW/7问/感激提问等价值观提问做教练；应对成员在面谈中倾诉私事；为不知道自己想干什么的成员做职业规划教练；探查成员工作动力（目的性/熟练度/自主性） |
| 三次反思与反学习节奏 | medium | 为重要会议或客户面谈做结构化准备（预会）；会议进行中关注成员状态并灵活调整；会后或项目后复盘并沉淀到下一次；定期召开团队反思会检视工作价值与无用功；识别并摒弃落伍的思维模式（反学习） |
| 因人而异沟通与情境领导 | medium | 判断对某个下属该用什么管理方式；骨干能力很强但明显懈怠时决定怎么管；新人热情但常出错时决定放手还是严管；检查自己是否在反馈/机会/考核上差别对待；让沟通方式适配不同性格的成员 |
| 减法评价与双轨反馈 | medium | 考核季给成员公正打分不凭印象；处理业绩很好但协作很差的成员怎么评；厘清一项业绩算个人功劳还是团队功劳；让评价面谈真正改变行为而不是年年重复评语 |
| 团队构成：迪士尼策略、跨度与文化扩展性 | medium | 组建或重组团队时决定招什么样的人；诊断团队创新乏力、讨论总是一边倒；判断一个管理者带多少人合适、要不要拆分；打破团队一成不变、设计人员流动；检查招聘标准是文化契合还是文化扩展 |

## 安装

```bash
./install.sh                      # 装到 ~/.zcode/skills/small-team-management
./install.sh ~/my-skills          # 或指定目录(FORCE=1 覆盖)
```

安装后 agent 在触发场景自动调用;也可直接阅读 `references/capabilities/` 下的能力卡,
每张卡为六段结构:R 原文摘引 / I 方法论骨架 / A1 书中应用 / A2 触发场景 / E 可执行步骤 / B 边界。

## 来源与可复现性

源电子书 → 结构+内容双重门禁 → cangjie 五阶段蒸馏 → 编译硬门禁(staging 校验)。
